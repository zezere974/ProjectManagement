Prérequis — ce qu'il faut avoir sur votre machine
Vérifications avant de commencer

Vérifiez que ces outils sont installés :

Terminal — vérification
python3 --version # doit afficher 3.11 ou supérieur git --version # doit afficher 2.x pip3 --version # doit être disponible
ℹ️
Python 3.11 ou 3.12 requis.
Si vous n'avez pas Python, téléchargez-le sur python.org (Windows) ou via brew install python@3.12 (macOS) ou sudo apt install python3.12 (Ubuntu/Debian).
⚠️
Windows uniquement : utilisez Git Bash ou WSL2 pour les commandes ci-dessous. L'invite de commandes cmd.exe n'est pas recommandée.

Créer et activer un environnement virtuel Python
Isoler les dépendances du projet
macOS / Linux
Windows (Git Bash)
macOS / Linux
# Créer l'environnement python3 -m venv .venv # Activer l'environnement source .venv/bin/activate # Votre terminal doit maintenant afficher (.venv) au début
Windows (Git Bash / WSL)
python -m venv .venv source .venv/Scripts/activate # Git Bash # OU .venv\Scripts\activate # CMD/PowerShell
✅
Bonne pratique : toujours activer le venv avant de travailler sur le projet. Vous le saurez si (.venv) apparaît dans votre terminal.

Installer les dépendances
~15–30 secondes selon votre connexion
# S'assurer que pip est à jour pip install --upgrade pip # Installer toutes les dépendances Phase 1 pip install -r requirements.txt

Vous verrez un affichage du type Successfully installed fastapi-0.115.x uvicorn-0.30.x ... à la fin.

ℹ️
requirements-phase2.txt et requirements-phase3.txt existent mais ne sont PAS nécessaires pour cette phase. Ne les installez pas encore.
5
Vérifier le fichier .env
Configuration de l'application — déjà préremplie pour le dev local

Un fichier .env fonctionnel est déjà inclus dans le dépôt. Pour le dev local, vous n'avez rien à modifier. Voici les valeurs importantes :

APP_PHASE=1 DATABASE_URL=sqlite:///./daily_mgmt.db # SQLite local, créé automatiquement APP_URL=http://localhost:8000 DEBUG=true SSO_ENABLED=false # SSO Microsoft désactivé en Phase 1 REPORTS_ENABLED=false # Rapports disponibles en Phase 2 TEAMS_ENABLED=false # Teams disponible en Phase 3
⚠️
En production, changez impérativement SECRET_KEY et JWT_SECRET_KEY par des valeurs aléatoires générées avec :
python3 -c "import secrets; print(secrets.token_hex(32))"

API REST disponible
Toutes les routes accessibles via Swagger sur /docs

Routes principales disponibles en Phase 1 :

POST/auth/login→ Authentification, retourne access + refresh token
POST/auth/refresh→ Renouveller l'access token
GET/api/dashboard→ KPIs globaux, alertes, PDCA
GET/api/projects→ Liste filtrée (status, priority, lean_phase, search)
POST/api/projects→ Créer un projet
GET/api/projects/{id}→ Détail + tâches + logs
PUT/api/projects/{id}→ Modifier un projet
DEL/api/projects/{id}→ Soft delete
POST/api/projects/{id}/flag→ Escalader un projet
POST/api/projects/{id}/daily-log→ Enregistrer le log du stand-up
GET/api/alerts→ Alertes actives / résolues
PUT/api/alerts/{id}/resolve→ Résoudre une alerte
GET/api/export/projects→ Export CSV ou JSON (?format=csv)
GET/api/team→ Membres de l'équipe
GET/api/reports/weekly→ HTTP 501 "Disponible en Phase 2"
POST/api/notifications/teams/test→ HTTP 501 "Disponible en Phase 3"

Dépannage courant
Problèmes fréquents et solutions

Erreur : ModuleNotFoundError: No module named 'app'

# Lancez uvicorn depuis la RACINE du projet (là où se trouve app/) pwd # doit afficher .../projectmanagement (PAS .../projectmanagement/app) uvicorn app.main:app --reload

Erreur : Address already in use (port 8000 occupé)

uvicorn app.main:app --reload --port 8001 # Puis accéder sur http://localhost:8001

Erreur bcrypt ou passlib

pip install passlib[bcrypt] --force-reinstall

La base de données semble vide ou corrompue

# Supprimer la base et laisser l'app la recréer rm daily_mgmt.db uvicorn app.main:app --reload

Les tests échouent avec des erreurs d'import

# S'assurer que le venv est activé et les dépendances installées pip install -r requirements.txt pytest tests/ -v
🛑
Ne pas installer requirements-phase2.txt ou requirements-phase3.txt en Phase 1 — certaines dépendances (weasyprint, pyodbc) nécessitent des outils système supplémentaires.
